# 73shu.cc 73书院（`scrape-73shu.js`）

与 book18 流程一致：分章进 `chapters/`，合并进 `merged/`（有 `--merge-title` 时以书名为文件名，否则为 `全文合并.txt`）。

## 域名镜像（重要）

`www.73shu.com` 已停站：对任意路径返回「抱歉，站点关闭」空壳页（`<title>` 即此文案）。同站点存活镜像为 **`www.73shu.cc`**（73书院，同一 `/{分类}/{书籍id}/` 结构）。脚本内置 `MIRROR_MAP`，传入 `.com` URL 会自动改写为 `.cc` 并提示。

## 目录页

格式：`/{category}/{bookId}/`，例如 `http://www.73shu.cc/124/124192/`

- 章节链接选择器：`#maina dl.chapter-list dd a`
- 全量章节在同一页（本书记录 15 章，均为「第N部分」），**无目录分页**
- 链接形如 `/124/124192/{数字ID}.html`（顺序数字，`chapterId` 即正文 ID）
- 目录页可能同时含「最新章节」等区域，脚本按路径正则 `^/{category}/{bookId}/{digits}\.html$` 过滤，只收章节链接

## 正文

- 选择器：`#content`
- **章内分屏**：长章节会拆成多页，URL 为 `/{category}/{bookId}/{id}.html`（第 1 页）与 `/{category}/{bookId}/{id}_2.html`（第 2 页，以此类推）。本书各章均为 **2 页**。第 1 页正文以「又只得…」等半句结尾，第 2 页续接；脚本按 `{id}_N.html` 顺序探测，`#content` 为空（或过短）即视为末页并停止。
- **注意：正文页顶部/底部的「下一页」直指下一章**（`{id+1}.html`），并非本章第 2 页，不能靠它翻章内分页；必须自行构造 `{id}_2.html` 探测。
- `#content` 内即纯小说文本（段落以全角空格缩进 + 空行）；末页末尾常有字面 `&lt;/p&gt;`（站点双转义残留），脚本以 `stripAdLines` 的 `<\/?p>|&lt;\/?p&gt;` 规则剔除，另以 `stripLeadingNoise` 兜底
- `h1` 与链接文字一致（如「第1部分」），分章文件名 `001_第1部分.txt`

## 用法

```bash
node gaode/73shu/scrape-73shu.js http://www.73shu.cc/124/124192/ --out-dir=novel-output/73shu-124192 --merge --merge-title=母子爱情（一）
# 或从停站 .com 传入（自动改写 .cc）：
node gaode/73shu/scrape-73shu.js http://www.73shu.com/124/124192/ --out-dir=novel-output/73shu-124192 --merge
```

试跑前 N 章：URL 后加数字，例如 `… 3`。

## 注意事项

- 章节标题为「第N部分」，语义较弱；合并时用 `--merge-title=` 指定书名（见 `novel-targets.json` 中 `73shu-124192` 目标）。
- 站点为 GBK 编码页面，但 `#content` 经浏览器解码为 UTF-8 文本，脚本不涉及转码。
- **重跑补齐分页**：已存在的分章文件（>100 字节）会被「已存在跳过」，需加 `--force` 强制重拉：
  ```bash
  node gaode/73shu/scrape-73shu.js http://www.73shu.cc/124/124192/ --out-dir=novel-output/73shu-124192 --merge --merge-title=母子爱情（一） --force
  ```
- 失败章节写入 `novel-output/<dir>/73shu_failures.jsonl`（`appendFailureLog`），不会中断主流程。
