# xbiquge345.com 笔趣阁小说网（`scrape-xbiquge345.js`）

与项目整体流程一致：分章进 `chapters/`，合并进 `merged/`（有 `--merge-title` 时以书名为文件名，否则为 `全文合并.txt`）。

## 目录页

格式：`https://www.xbiquge345.com/book/{bookId}/`，例如 `https://www.xbiquge345.com/book/80767/`（大漠谣，桐华）

- 章节链接选择器：`div.border ul.info a`（每章一个 `li > a`，DOM 顺序即阅读顺序：第 1 章 → 第 N 章，**无需二次排序**）
- 全量章节在同一页（本书 86 章），**无目录分页**
- 链接形如 `/chapter/{bookId}/{数字ID}.html`，ID 非顺序（本书第 1 章 ID 为 `44932784`），正文顺序以目录 DOM 顺序为准
- 目录页含「最新章节」等侧栏区域（`ul.xinchapter` 等），但脚本优先读取 `div.border ul.info`；该容器为空时才回退整页扫描并按 href 去重

## 正文

- 选择器：`#txt`（章节页正文容器；`h1` 即章标题）
- **每章单页，无章内分屏**：正文页顶部/底部「下一章」指向下一章，脚本不依赖它，直接按目录链接逐章抓取
- 文本为 `<br>` 分隔段落，段首有 4 个全角空格缩进；正文顶部有一行广告提示「一秒记住【笔趣阁小说网】xbiquge345.com，更新快，无弹窗！」；脚本对每行 `trim()` 去缩进、剔除命中 `AD_RE` 的广告行
- 章尾干净，无残留尾巴；未映射图片等场景本项目未见（无需 `timg-map`）

## 用法

```bash
node gaode/xbiquge345/scrape-xbiquge345.js https://www.xbiquge345.com/book/80767/ --out-dir=novel-output/xbiquge345-80767 --merge --merge-title=大漠谣
```

试跑前 N 章：URL 后加数字，例如 `… 3`。

## 注意事项

- 目录页加载为轻量页，章节链接在 `domcontentloaded` 后即存在；脚本用「整页存在 `/chapter/{bookId}/` 链接」作为目录就绪探针。
- 站点默认页面为 GBK 编码 HTML，但浏览器已解码为 UTF-8 文本，脚本不涉及转码。
- **重跑补齐**：已存在的分章文件（>100 字节）会被「已存在跳过」，需加 `--force` 强制重拉：
  ```bash
  node gaode/xbiquge345/scrape-xbiquge345.js https://www.xbiquge345.com/book/80767/ --out-dir=novel-output/xbiquge345-80767 --merge --merge-title=大漠谣 --force
  ```
- 失败章节写入 `novel-output/<dir>/xbiquge345_failures.jsonl`（`appendFailureLog`），不会中断主流程。
